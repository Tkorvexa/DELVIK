# DELVIK Content-to-Enquiry System

## Objective
Turn each useful Instagram/Reel topic into a permanent DELVIK web asset that can rank in search, build technical authority and create a direct path to a project enquiry.

## Core funnel
1. **Short-form hook** — Reel/carousel answers one practical question and invites a keyword comment.
2. **Keyword response** — public reply confirms the resource has been sent.
3. **DM link** — send the matching DELVIK Insight URL, not a standalone PDF.
4. **Insight page** — long-form answer, source links, internal links and project CTA.
5. **Commercial page** — route the reader to the relevant service/area page.
6. **Enquiry** — project-specific CTA to /contact-build.

## Content families
Keep one website hub: **/insights**. Do not create disconnected “Tips”, “Advice” and “Blog” sections.

Use three editorial labels inside Insights:
- **Site Details** — cladding, joinery, framing, decks, fixing, sequencing, QA.
- **Building Advice** — pricing, renovation planning, consent, contracts, handover.
- **Development Insights** — subdivision, buildability, feasibility, multi-unit delivery.

## Keyword-comment library
Use one memorable keyword per topic:
- CLADDING → /insights/cladding-window-details
- PRICE → /insights/information-builder-needs-before-pricing
- RENOVATION → /insights/tauranga-renovation-cost-guide-2026
- DECK → future deck drainage/fixing guide
- FRAME → future framing/bracing guide
- DEVELOPMENT → future 2–4 unit buildability guide

## Required page pattern
Every new Insight should include:
- Search-intent-focused title and meta description.
- One H1 and clear H2 sections.
- Article + Breadcrumb structured data.
- Author/date and general-information disclaimer.
- Primary NZ sources for technical/regulatory claims.
- 2–4 internal links to service, area and related Insight pages.
- One commercial CTA matched to the topic.
- A corresponding social response file in /social.
- Sitemap entry.
- Insights-hub card.

## Social production loop
For every Insight create:
- 1 Reel hook + 20–40 sec script.
- 1 carousel with 5–8 slides.
- 3 Stories: question, takeaway, link.
- 1 Instagram caption.
- 1 LinkedIn post.
- 1 Google Business Profile post.
- Keyword-comment response.
- Track: comments, saves, link clicks, profile visits and qualified enquiries.

## Quality rule
Do not turn a generic technical diagram into a project-specific instruction. Use project documents, manufacturer details and the current compliance pathway for actual construction. Do not present stock or third-party work as a DELVIK project.

## Internal-link rule
Each new Site Details article must link to:
- the most relevant service page,
- at least one location page where applicable,
- one related Insight,
- /contact-build.

The service/location page should link back to the Insight where it materially improves the page.

## Publishing cadence
- Monday: choose one real customer/site question and keyword.
- Tuesday: draft and source the Insight.
- Wednesday: publish the site article and update sitemap/internal links.
- Thursday: publish Reel/carousel and activate the keyword response.
- Friday: capture comments/questions for the next topic.
